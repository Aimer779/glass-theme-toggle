# 玻璃昼夜开关

根据用户提供的 14.4 秒视频独立实现。
包含玻璃滑块、像素太阳与月亮、粒子聚散和轮廓流光。
页面右侧提供实际响应曲线和 20 项实时参数。
窄屏时面板移到预览下方。

## 打开

本地预览：http://127.0.0.1:18240

也可以直接打开 `index.html`。项目不需要安装依赖。

## 调整

- 拖动或点击开关，或聚焦后按空格、Enter，切换昼夜。
- 按住可停留在中间态。向两端继续拖动可感受弹性阻力。
- 松手后按位置与速度吸附到端点。Esc 取消本次拖动。
- 调整宽度、圆角、不透明度和模糊，改变玻璃外观。
- 调整弹簧刚度、回弹阻尼、边界弹性和挤压幅度。
- 调整高光跟随时间、粒子散开幅度和像素大小。
- 调整亮边长度、线宽、间距、光晕和内部受光。
- 参数实时生效。运动响应继承当前位移与速度。
- 窄屏自动限制开关宽度。圆角和像素按实际尺寸等比缩放。
- 参数自动保存在当前浏览器。刷新后恢复参数，主题从夜间开始。
- “导出参数”下载 JSON。“恢复默认”仅重置本实验参数。
- “隐藏参数”扩大预览区域。再次点击恢复面板。

系统启用减少动态效果时，主题直接切换。
连续回弹与闪烁停止，拖动仍可直接查看中间态。
此时仍可使用时间游标查看已记录的静态帧。

## 动画曲线

- 选择位移、横向形变、纵向形变、高光相位或图案过渡。
- 曲线记录实际操作，包含超调、停留和反向。
- 拖动时间游标可定格。方向键也可调整游标。
- “继续播放”从定格位置回放剩余记录。
- “重播”重现最近一次操作。没有记录时演示一次切换。
- 拖动开关可接管正在运动或回放的画面。

记录最多保留最近 900 帧。曲线会调整坐标范围。
相位以连续角度显示，避免跨过 0° 时跳变。

白昼高光以顶部为中心，夜间以底部为中心。
调整圆角和长度时，亮边两端保持左右对称。
稳定态停止流动，已移除旧版闲置流速参数。
完整切换默认沿视频确认的逆时针路径。
运动中反向时保留路径分支，沿当前路径返回。
原视频没有输入事件记录，方向选择规则属于重建假设。

中点停稳后，滑块轻微收缩；拉伸主要来自运动速度。
背景、轨道、玻璃分别映射亮度，避免中间态过暗。
轨道宽高比为 1.94。默认宽度 420px 时高约 216.5px。

## 文件

- `index.html`：开关与参数面板结构。
- `styles.css`：布局、玻璃材质与轮廓光。
- `dynamics.js`：像素图案、确定性随机数和参数校验。
- `motion.js`：弹簧、边界阻力、形变与相位分支。
- `gesture.js`：鼠标、触摸、指针捕获与取消。
- `particles.js`：按滑块位置绘制粒子形态。
- `settings.js`：参数控件、持久化、导出和重置。
- `curve-panel.js`：实际响应曲线、时间游标和回放控件。
- `script.js`：渲染、操作记录与回放。
- `evidence/`：本地参考帧、页面截图与检查结果。

此实验使用独立的本地 Git 仓库。

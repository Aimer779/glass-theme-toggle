# 玻璃昼夜开关

根据用户提供的 14.4 秒视频独立实现。
包含玻璃滑块、像素太阳与月亮、粒子聚散和轮廓流光。
页面右侧提供动画曲线和 17 项实时参数。
窄屏时面板移到预览下方。

## 打开

本地预览：http://127.0.0.1:18240

也可以直接打开 `index.html`。项目不需要安装依赖。
浏览器对 `file://` 的本地保存行为存在差异。
需要可靠保存时，使用本地预览地址。

```powershell
python -X utf8 C:/Users/Max/.codex/skills/dev-servers/scripts/cli.py start glass-toggle --project D:/code/frontend-test/glass-theme-toggle
```

## 调整

- 点击开关，或聚焦后按空格、Enter，切换昼夜。
- 调整宽度、圆角、不透明度和模糊，改变玻璃外观。
- 调整时长、缓出强度、散开幅度和像素大小。
- 调整亮边长度、线宽、间距、光晕和内部受光。
- 所有参数实时生效。修改时长保持当前时间进度。
- 窄屏自动限制开关宽度。圆角和像素按实际尺寸等比缩放。
- 参数自动保存在当前浏览器。刷新后恢复参数，主题从夜间开始。
- “导出参数”下载 JSON。“恢复默认”仅重置本实验参数。
- “隐藏参数”扩大预览区域。再次点击恢复面板。

系统启用减少动态效果时，主题直接切换。
粒子聚散、闪烁和流光运动均停止。
此时仍可使用时间游标查看静态中间帧。

## 动画曲线

- 选择滑块位移、粒子聚合或高光进度。
- 曲线与实际动画共用函数。亮点表示当前进度。
- 缓出强度作用于位移和高光，粒子采用平滑聚合曲线。
- 拖动时间游标可定格，方向键也可调整游标。
- “继续播放”从当前定格位置继续。
- “重播”从起点重播当前方向。
- 点击开关可从当前位置反向。

白昼高光以顶部为中心，夜间以底部为中心。
调整圆角和长度时，亮边两端保持左右对称。
稳定态停止流动，已移除旧版闲置流速参数。

## 文件

- `index.html`：开关与参数面板结构。
- `styles.css`：布局、玻璃材质与轮廓光。
- `dynamics.js`：像素图案、确定性随机数和参数校验。
- `settings.js`：参数控件、持久化、导出和重置。
- `curve-panel.js`：曲线绘制、进度显示和回放控件。
- `script.js`：动画时间轴、Canvas 绘制和轮廓光。
- `evidence/`：本地参考帧、页面截图与检查结果。

此实验使用独立的本地 Git 仓库。
